# 理解性测评题单草案 v1

供人工审阅。6 个冻结时刻，每个时刻 3 题，共 18 题。题目逐题独立启动沙盒及空对话。尚未运行模型测评。

## 数据和模拟约定

- 用户为 Eva。源文件为 `.timeline_kens/evaluation-initial-2026-11.db`。
- 源文件 SHA256 为 `8406095cbe290bf4ed0d084abac10849e98c1a7a88c61141fd6c7a16567b094a`。
- 班表和档案在所有案例开始前已知。数据库内现有的 baseline 睡眠建议预先可见，保留其 proposed、planned 状态。
- 实际睡眠在结束时立即报告，结束时刻不晚于冻结时刻才可见。尚未结束的实际睡眠整条隐藏。本版不模拟进行中睡眠。
- 上述是为模拟设置的知识可见时间。库内很多记录在 11 月 18 日集中补录，created_at 无法直接表达这些较早时刻的模拟知识状态。
- 历史实际记录后来结束，不能让早期沙盒获得其开始时间或最终时长。历史 actual 对应的旧计划也不能凭空恢复。
- 18 日之后沿用这份静态备份。经过某项建议的结束时间，只改变时间关系，不把建议转换为实际记录。
- 航班的进行中、已结束等描述仅指班表时间关系。航班到达时刻不能证明实际到达、用户实际位置或用户已经睡过。
- 问题里的时间都带日期和 IANA 时区。区间采用左闭右开，时长按 UTC 实际经过分钟数计算，跨窗口时取交集，同一时间重复记录只计一次。

## 输出和评分

统一提交 JSON 对象，包含 question_id、answer、evidence_event_ids。单选 answer 为选项字符串，多选为无重复选项数组，事实题为下文指定字段对象。

所有题的 JSON schema 禁止额外字段。事件 ID、状态和选项精确匹配，选项集合无序比较，时间解析为绝对时刻后精确比较，分钟数为整数且无容差。要求本地表示的题同时检查指定 timezone 和该时区偏移，防止仅返回等价 UTC 时间。

每题记录 format_valid、answer_correct、evidence_correct、passed。passed 要求前三者均成立。18 题等权，每题 1 分，无部分分。失败、超时、预算耗尽均纳入分母。可另报字段正确率和集合 precision/recall 作诊断。

下文 S/F 编号仅为审阅用证据别名，实际答卷使用工具返回的原始事件 ID。正证据按表中集合完全匹配。关于缺少记录的判断，以成功观察完整指定窗口为覆盖证据，不要求为不存在的事件提供 ID。Q13、Q16 需要对应窗口观察记录，Q08 需要 location 轨道观察记录。

题目、冻结时刻、答案 schema 和选项提供给模型。标准答案、证据别名表及解题说明只供评分器和审阅者读取。
